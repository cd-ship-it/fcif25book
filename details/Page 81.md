# 回到聖經：重新思想姊妹在教會中的事奉

*黎慧琪｜三藩市金門基督教會牧師*

當我們思想「姊妹在教會中事奉」時，不應只從文化傳統、個人習慣或過去經驗出發，而應當回到神的話語，認真尋問：「聖經到底怎樣教導我們？」

我從小在教會長大。從幼稚園到大學，我都以為只有弟兄才能擔任牧師、長老和執事。那時我不清楚聖經的教導，也未曾深入研究，只是順著傳統走。來到北美教會後，這觀念仍深深影響我。我自然認為：「一直都是這樣，應該沒錯。」

有時我們以為自己相信的是聖經，其實只是傳統塑造的觀念。因此，我們需要重新回到聖經，認真查考神的話。

聖經對教會的領導、權柄與秩序有明確教導（如提摩太前書二11–15、三1–13及提多書一5–9）。這些經文值得我們謙卑、仔細地研究，而非只按個人立場來解釋。

深入查考聖經不是為了贏得辯論，而是為了更深認識神並遵行祂的旨意。讓我們勇敢地問：「神的話到底怎樣教導？」也謙卑地讓神的話糾正與更新我們。屬靈成熟不是堅持從小接受的傳統，而是讓真理改變我們。

「基督豐榮團契」正是幫助姊妹事奉的平台。在這裡，我們彼此鼓勵，坦誠分享事奉中的困難與挑戰。願我們透過學習與分享，更深明白神的話，釐清恩賜與呼召，在基督裡一同成長、忠心服事。
