# 團契與靈命塑造經歷談

*黃惠蘭*

在每個月一次南加州洛杉磯「基督豐榮團契」 聚會中，我們每年通常會選一本屬靈生命的書籍來讀，《屬靈操練禮讚》是我們今年閲讀的書。一次聚集、一起吃飯、敬拜及分享閲讀心得及操練；談自己的經歷、軟弱與掙扎，互相鼓勵支持與代禱，一起經歷靈命成長。

傅士德（1989/1993， 9-13頁) 《屬靈操練禮讚（增修版）》中提到 :「屬靈生命操練的目的是要把人從那令人窒息的自私自利和恐懼的奴役中釋放出來。」而這些操練最好在人際關係中實施，因為當我們與人相處時，那些設法掩藏的性格容易暴露出來，這帶來看清內心需要的改變，並回轉向神，操練內在與靈性實體，經歷與神親密的交通。

屬靈生命的塑造關乎我們與神與人恢復關係及結連，在關係中成長。支取神的恩典，渴慕主、愛主，以及彼此相愛的心是靈命塑造操練的動力。

這次廿五週年豐榮大會雖已報名，但仍有一些考慮  — 機票、機場接送、旅館住宿等。在操練禱告與默想中神提醒我 : 去看老朋友。當這個意念進來時，喜樂湧上心頭。是的，去看老朋友，值得付出一切，顧慮都可放下。神調整我的看法，讓我的價值觀、思想與神對焦了。
